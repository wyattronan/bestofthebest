# Philadelphia — pulled lists (Nov 14 2026)

Lists I pulled directly this session, plus source links for the ones blocked
or paywalled in this environment (pull those via the Chrome extension).

**Coverage note:** Philadelphia has **no Michelin guide** (not a Michelin
region), so — like Phoenix — the backbone is local + national editorial:
The Infatuation, Philadelphia Magazine (Foobooz), Time Out, Eater, the
Inquirer (Craig LaBan), PUNCH, and the James Beard Awards (Philly is a JB
Best Chef: Mid-Atlantic powerhouse). Restaurant coverage is strong (three
**ranked** lists); bars are solid.
